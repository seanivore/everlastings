## Cross-cutting invariants (hold across every workstream)

- **`is_test` isolation.** A test-preview action never touches a live row: a live order id 404s on the test refund/mark-ship path; `GET /api/orders?payment_intent=<a live PI>` returns `{orders:[]}`; the `active_sale` read returns TEST codes (env-scoped Stripe key); `activity_log` + orders + products reads are all `isTest`-scoped; seen/unseen uses the `_test` key. CDN keys stay under `test/…`.
- **Sold-policy consistency across the FOUR enforcers.** The state model is honored identically in the portal's `computeState()` (sold = qty0 from a sale, never the toggle), the storefront buy-gate (`published && quantity > 0`), the webhook decrement (`record_sale` — `available = quantity>0`, `greatest(…,0)` never negative), and the deliberately-stricter server checkout/reserve gate (`checkout.ts:79`/`:205` — `is_published===true && available===true && quantity>=1`, also rejects archived). Cross-check the 4th-enforcer edges: a `quantity>0 & available===false` row renders buyable but **410s at checkout** (no buy leak); a `quantity=null & available===true` row is treated unavailable server-side.
- **Brand separation.** The portal is cool indigo-slate; the storefront's warm-plum brand is untouched except the WS6 fixes + the WS4 struck-price/top-bar/popup additions (storefront tokens). No portal token leaks into the shopper pages and vice-versa; no bare hex where a `var(--token)` should be.
- **Reduced-motion preserved.** Portal motion honors `prefers-reduced-motion`; the storefront hero's fallback stays; the WS4 sale popup animation is gated behind `no-preference`.
- **No hard delete anywhere.** "Delete" = archive; everything is revivable. A price change creates a new Stripe Price and deactivates the old — never an in-place edit.
- **Money in integer cents.** Every price/amount is stored + compared as integer cents; rendered via `formatPrice()` / `PORTAL_DATA.money()`; the struck-price helper computes `Math.round(cents * (1 - value/100))` — never dollars.
- **CommonJS / tsc-clean + function/cron count unchanged** (re-assert the static gate after the final fold): `npx tsc --noEmit` clean, 11/12 functions, 1 cron, GPT `.txt` under 8000, CORS unaffected (`*.vercel.app` allowlist), `main` untouched throughout.
